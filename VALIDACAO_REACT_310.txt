VALIDAÇÃO — ERRO REACT #310

CAUSA IDENTIFICADA
- O componente principal possuía um useCallback (carregarComissoes) depois dos retornos condicionais de loading/login.
- No primeiro render esse Hook não era executado; no render seguinte ele era executado.
- Isso violava a ordem fixa dos Hooks do React e gerava o erro minificado #310.

CORREÇÃO
- carregarComissoes deixou de ser Hook condicional e passou a ser função normal.
- Todos os Hooks do componente principal ficam antes dos retornos condicionais de loading/login.
- O Error Boundary foi mantido para exibir diagnóstico caso outro erro de interface ocorra.

VERIFICAÇÕES
- api/data.js: node --check executado com sucesso.
- Busca estática confirmou que não há Hooks do componente principal após os retornos condicionais de loading/login.
- O build Vite completo não foi concluído neste ambiente porque as dependências npm não puderam ser reinstaladas dentro do tempo disponível; não é alegado como teste concluído.
